Aotearoa Treasures Ltd. is a boutique retailer specializing in New Zealand-made handicrafts and souvenirs, with stores located in Wellington CBD, Christchurch, and Auckland. This project delivers a centralized inventory and staff management system to streamline operations across all locations.

Project Overview

  Administrator (Owner)
    Monitor inventory across all stores
    Identify low-stock items (less than 5 units)
    Add, update, and delete product entries
    View and manage weekly staff rosters
    Add, update, and delete employee records
  
  Customers (general users)
    Select a store
    Browse and purchase products
    Automatically update store inventory upon purchase

Objectives

  Centralize stock control across all branches
  Improve visibility of product availability
  Streamline employee scheduling
  Provide role-based access for admin and users
